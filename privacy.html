Politique de Confidentialité / Privacy Policy

Dernière mise à jour : 2 septembre 2026

1. Qui sommes-nous ? / Who we are

Art&Fun est une boutique en ligne de t-shirts originaux exploitée par un entrepreneur individuel. Notre site est hébergé sur GitHub Pages et notre boutique principale se trouve sur Redbubble.

Art&Fun is an online t-shirt store run by a sole proprietor. Our site is hosted on GitHub Pages and our main store is on Redbubble.

2. Données collectées / Data we collect

Nous ne collectons aucune donnée personnelle directement sur ce site. Ce site est statique et ne dispose pas de formulaire de contact, de panier, ni de système de connexion.

We do not collect any personal data directly on this site. This is a static website with no contact forms, shopping cart, or login system.

3. Hébergement / Hosting

Ce site est hébergé par GitHub Pages (GitHub, Inc.). GitHub peut collecter des données techniques (adresse IP, type de navigateur) conformément à leur propre politique de confidentialité.

This site is hosted by GitHub Pages (GitHub, Inc.). GitHub may collect technical data (IP address, browser type) in accordance with their own privacy policy.

4. Liens externes / External links

Ce site contient des liens vers notre boutique Redbubble. Redbubble collecte et traite les données conformément à sa propre politique de confidentialité.

This site contains links to our Redbubble store. Redbubble collects and processes data in accordance with its own privacy policy.

5. Pinterest API / Pinterest API

Nous utilisons l'API Pinterest pour publier automatiquement des pins promotionnels. Lors de l'utilisation de cette API, Pinterest collecte des données techniques conformément à ses propres conditions d'utilisation.

We use the Pinterest API to automatically publish promotional pins. When using this API, Pinterest collects technical data in accordance with its own terms of service.

6. Cookies / Cookies

Ce site n'utilise aucun cookie.

This site does not use any cookies.

7. Vos droits / Your rights

Conformément au RGPD, vous disposez d'un droit d'accès, de rectification et de suppression de vos données. Étant donné que nous ne collectons pas de données personnelles, ces droits ne s'appliquent pas directement à ce site.

Under GDPR, you have rights of access, rectification, and deletion of your data. Since we do not collect personal data, these rights do not directly apply to this site.

8. Contact / Contact

Pour toute question concernant cette politique, contactez-nous via notre boutique Redbubble.

For any questions about this policy, contact us via our Redbubble store.
